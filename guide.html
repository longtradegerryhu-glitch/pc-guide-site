电脑使用指南（小白版）

看不懂术语别慌，这一页专门用大白话讲——照着做，电脑更好用、也不容易坏。

🙋 小白先记住这 3 句话：

1. 电脑卡，多半是「开机自启太多」或「内存不够 / 硬盘太老」，不是机器真坏了。

2. 文件别只放一处，云盘 + U 盘/移动硬盘各留一份，电脑坏了也不慌。

3. 装软件去官网，别点「高速下载 / 一键安装」里偷偷勾的小选项，最容易中招。

⚙️

让电脑跑得更快（系统优化）

· 开机慢？管「自启」：按 Ctrl+Shift+Esc 打开任务管理器 → 点「启动」→ 把不常用的右键「禁用」，开机能从1分钟变20秒。
· 笔记本：插电时用「高性能」更顺畅，出门用「省电」续航更久。
· 系统更新别关，安全补丁很重要；大升级前先备份。
· 老电脑提速：把透明特效、动画关一关，能腾出一点性能。
· 硬盘：装系统要用 SSD（固态硬盘），它不用「碎片整理」——那是老式机械硬盘的事。

🗂️

文件别乱丢（文件管理）

· 桌面只放临时文件，长期用的按「项目 / 年份」建文件夹分层放。
· 备份记住「3-2-1」：3 份、2 种介质（比如电脑 + 移动硬盘）、1 份放别处（云盘）。
· 双保险：重要文件云盘同步 + 移动硬盘各留一份。
· 空间不够：用系统「存储感知」清垃圾、卸掉不用的软件。

🧩

这些软件真的好用（避坑版）

· 办公：Office 或 WPS、浏览器（Edge / Chrome）。
· 找文件快：Everything（输名字秒出结果）。
· 截图贴图：Snipaste；解压：7-Zip / Bandizip（别装某压，广告多）。
· 看片：VLC / PotPlayer，啥格式都吃得下。
· 清理：Dism++ 或系统自带，别装「电脑管家全家桶」，越管越卡。

🛡️

防病毒 + 定期保养

· 杀毒：Win10/11 自带的 Defender 就够，不用再装第三方「全家桶」。
· 密码：用密码管理器记，重要账号开「两步验证」（2FA）。
· 每月 5 分钟：清灰、查更新、确认备份还能用。
· 重要电脑做个「系统镜像」，万一崩了能整盘还原。

SCENARIOS

先想清楚：你主要拿来干嘛？

用途不同，钱该花的地方也不同。对号入座，别跟风乱买。

📚

办公 / 学习

重点就俩字：安静、不累。笔记本垫高、用静音风扇； 显示器抬高或接双屏，效率更高；资料勤备份，丢不了。

🎮

游戏 / 电竞

重点：散热 + 画面流畅。散热要够（风冷 / 水冷）， 显示器选高刷（144Hz 以上）少拖影；笔记本配散热底座，长时间不降频。

🎬

内容创作

重点：快 + 颜色准。显卡显存大（渲染快）、 显示器色域广（颜色不偏）、散热好（导出不卡）。

🎒

移动 / 便携

重点：轻 + 续航。带散热支架、拓展坞补接口、轻量键鼠随行； 文件丢云盘，随时取用。

HARDWARE

配套硬件总结（大白话版）

买电脑 / 配件前，先看懂这几样是干啥的。记不住参数没关系，记住「它像什么」就行。

🧠 一句话类比，先建立感觉：

· CPU = 大脑（干活快慢）　· GPU 显卡 = 画师（画面 / 游戏 / 剪辑）

· 内存 = 桌面面积（能同时摊开多少东西）　· 硬盘 = 柜子（能存多少东西）

· 主板 = 骨架（把大家连一起）　· 电源 = 心脏（供电稳不稳）

核心部件

🔲

CPU 处理器（大脑）

管电脑「干活的快慢」。核数多 = 能同时干多件事（剪辑、多开网页）； 主频高 = 单件事反应快（打游戏更跟手）。
买前注意：它和主板插口要对上，Intel 和 AMD 不通用。

🎮

GPU 显卡（画师）

管「画面」：打游戏看帧率，做图 / 剪辑看显存（越大越能扛大工程）。 普通办公用 核显（CPU 自带）就够，还能省一笔钱。

🧠

内存（桌面面积）

8G 勉强、16G 舒服、32G 创作 / 多开不卡。两根组「双通道」更快。 老机加内存，是最划算的提速办法。

💾

存储（柜子）

系统盘必须 SSD（固态），开机几秒、打开软件快。 机械硬盘只当仓库存电影照片。看速度别只看容量——日常卡不卡，看「4K 随机读写」。

🔌

主板（骨架）

决定能插多少硬件、能不能超频。插座要和 CPU 对上； 看 USB、M.2 接口数量够不够用。

🔋

电源（心脏）

功率留 30% 余量，认 80 PLUS 认证。别买杂牌——它一炸，全家遭殃。 优先选品牌、长质保。

外设与网络

🖥️

显示器（窗户）

尺寸分辨率：24寸1080p / 27寸2K / 32寸4K；打游戏看刷新率 144Hz+； 做图看色域广不广；IPS 面板颜色正、看着舒服。

⌨️

键鼠

键盘红轴顺滑、茶轴有段落感、静音轴不吵；鼠标看「准星稳不稳」（传感器 / DPI）。 手大选手掌贴合的，久用不累。

🎧

音频设备

耳机封闭款隔音（宿舍 / 图书馆），开放款声场大（在家听歌）； 开会 / 直播看麦克风。别为参数堆设备，够用就好。

📶

网络设备

路由器认 Wi-Fi 6 以上；房子大用 Mesh 多台组网； 网线 Cat5e 起步；台式机插网线比 Wi-Fi 稳。

散热与支架

❄️

散热器

风冷 = 便宜耐用（中端够用）；水冷 = 压旗舰、好看，但贵且有漏液风险。 笔记本加散热底座能降几度。记住：清灰 + 换硅脂，老机回春。

🪧

支架

显示器支架能升降旋转，脖子不酸； 笔记本支架抬高视线 + 底部进风。理好线，桌面清爽也利于散热。
